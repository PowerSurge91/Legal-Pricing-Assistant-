Using it

  1. Download the file. It lands in your Downloads folder as pricing-assistant.html.
  2. Double-click it. It opens in your default browser. There is no install step.
  3. Work in it. Load a rate card, price the matter, export to Excel or PDF.
  4. Keep it. Move it anywhere — a USB stick, a network drive, an email attachment. It keeps working, online or off.

Make it yours

This is a starting point, not a finished product.

It was built quickly, for a conference talk, around one set of assumptions. It is opinionated, it has rough edges, and it almost certainly does not match how your firm prices. That is the point — it is meant to be taken apart.

It is a single HTML file with readable source. You do not need a developer and you do not need to learn to code: open it, or hand it to an AI assistant, describe the change in plain English, and get an edited file back. Then keep going.

What people change first

  • The rate card. Swap the sample timekeepers for your own — Settings does this without touching any code.
  • The thresholds. Realization floor, profit target, profit floor. They drive every KPI colour in the tool.
  • The scenarios. Discount tiers and rate-increase percentages, so the comparisons match the conversations you actually have.
  • The phases and tasks in the budget view, to match your own matter taxonomy.
  • The letterhead and export wording, so what comes out looks like it came from you.
  • The KPIs themselves. Add the numbers your partners argue about, and drop the ones they don't.
A practical note on using AI tools. The downloaded file is 2.4 MB, and most of that is bundled libraries that will crowd an AI's context window for no benefit. Start from the source file instead — the same application, without the libraries. The rate data sits between two clearly marked comments so it is easy to point at.
