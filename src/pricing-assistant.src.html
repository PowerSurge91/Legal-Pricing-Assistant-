1

Rate Data Management

Updating the timekeeper rates (do this when a new rate file is issued):
  1. Click Upload Updated Rate File and choose the latest full rate file (Excel or CSV). Always upload the complete roster — the update replaces the whole list, so departed timekeepers drop off and new joiners are added automatically.
  2. Check the column mapping. The tool matches columns by their headers; fix any dropdown it got wrong. Rates can be mapped separately for USD, GBP, and EUR.
  3. Review the preview and change summary (how many retained / new / removed) and any warnings about skipped rows.
  4. Click Save Rate Update to File and select this app's file when the file picker opens. The rates are written into the app itself, so everyone opening it from the shared drive sees the update.
The "Last updated" timestamp below is written automatically on every save, for record keeping. Nothing is changed until you confirm the save — cancelling at any point leaves the current rates untouched.

3 Analysis Setup
What this step does: choose what kind of analysis you need, build the team, then run it.
  • Blended Rate — "what's the average hourly rate for this proposed team?" Pick timekeepers, enter hours, and get the weighted rate with discount and margin scenarios.
  • Rate Increase — "what happens if we raise this client's rates?" Compare current vs. standard rates and model increase percentages.
  • Rate Proposals & Ranges — "what rates should we include in this pitch?" Build a pitch-ready view with market ranges by title and named key team members.
  • Budget — "what will this work cost by phase and task?" Build phase/task budgets by timekeeper, model adjustments, and produce a client-friendly summary.
  • Fixed Fee — "can we do this work for $500k?" Test a proposed fee against the cost of the team to see realization and margin.
  • Write-off — "how much of this bill can we write off before profitability breaks?" Matter-level scenarios against the CFO's 20% target / 10% floor.
  1. Select the analysis type — the right inputs appear automatically.
  2. For team-based analyses: search and add timekeepers by name, ID, title, practice, or office, then enter each person's hours.
  3. For Blended/Fixed Fee: use Staffing Plans to compare alternative team mixes side by side (e.g. partner-heavy vs. associate-heavy).
  4. Click Run Analysis.
Tip: "Customize Scenarios" lets you change the default discount tiers (10% / 20%) and margin targets (45% / 50%) before running.

4 Output
Reading the results:
  • The summary cards at the top give the headline numbers. A gold or red accent means a figure is below target — hover the card for emphasis, and check its caption for the reason.
  • Realization % = what you'd collect as a share of full standard rates. Profit Margin % = what's left after cost. Both appear in every scenario table.
  • Each table has its own Copy Table button — it copies with formatting that pastes cleanly into Outlook, Word, or Excel.
Sharing the analysis:
  • Print / PDF — a print-ready document with your firm name, matter, and confidentiality footer (Write-off analyses produce a formatted PDF automatically).
  • Export Excel — a working model, not a static dump: an Inputs sheet (blue cells are editable — rates, hours, discounts, scenario values) and a Summary sheet driven entirely by formulas. Change any input in Excel and the whole workbook recalculates.
  • Email Draft (.eml) — a pre-formatted email; open it in Outlook, add recipients, and send.
